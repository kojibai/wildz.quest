# Shared journey

Approved brief: execute the six player-experience priorities from this task.

The loop is explore with a companion, discover something useful, gather and build a home, then return together. Preserve existing proof admission, conservation, traversal and combat rules. Add grounded local memories of observed events, contextual next steps using spendable material counts, directions to actual nearby undiscovered sites, and shelter rest using the existing camp recovery rule. Never invent prior meetings for imported creatures or award resources for merely viewing a panel.

The Living Story drawer hosts next steps, home and journal. Existing mission HUD opens it. Buttons dispatch existing world actions and close the drawer where required. No new permanent HUD obstruction. Harvest animation starts immediately; confirmed rewards do not wait on an artificial timer.

Playtest recording is opt-in, local, bounded and exportable. Record frame stalls and coarse action outcomes without identities or locations. Human delight/hesitation requires actual player observation; no automated claim that this is the best game ever.

Acceptance: existing saves remain compatible; journals isolate owners and survive reload; only confirmed work generates success memories; next steps use real costs; home requires actual owned shelter and proximity; discovery guidance uses real site geometry; metrics stop when disabled/hidden; accessible mobile drawer; full tests/typecheck/build and browser interaction evidence.
