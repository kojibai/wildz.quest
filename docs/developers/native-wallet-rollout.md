# Native wallet implementation and rollout

The requested direct Phi sends, creature/resource gifts and mixed bilateral trades have a source implementation. Local synthetic SDK proofs and isolated PostgreSQL checks qualify implementation mechanics. They do not establish production deployment or a live payment.

## Source and authority

Wildz uses the public v128 native value-source, nativeTrade and nativeWorld APIs. The package version remains 128.0.0, constitutional ruleset 127.0.0 and frozen registry/matrix identities remain unchanged. Reproducible pnpm patches carry the coordinated additive SDK, MCP and AI changes; the public npm packages have not been republished.

The local Receiz host implementation is in the adjacent Receiz repository. Its native trade and native world routes authenticate the actual device/account/application and verify exact Original bytes, signed approvals, pinned acceptance and current global predecessor heads. Messages coordinate offers; they never confer custody or settlement authority. Direct Phi Send uses the genuine native source and exact-attempt SDK execution/recovery. Asset gifts require explicit recipient acceptance. Trades require both peers to approve the same final package and settle every leg in one transaction.

Complete accepted proofs are retained before projecting received assets. Cold restart re-verifies the entire root-accepted proof. A local storage or adoption failure exposes Refresh received assets and resolves the same receipt without another settlement. Full native carriers retain their signed proof even when an optional compact display URL cannot contain it; compact URL limits remain unchanged.

World resources originate in the replay of the actual 124-file Wildz law bundle. Native packaging and unpacking bind the current world head and signed source; native consumption participates in immutable global custody. Older local food, tools, groves and animals keep their established local behavior, without becoming native transferable assets. Saved native-food classification forbids local consumption before background native hydration; it grants no custody.
