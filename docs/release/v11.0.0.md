# Wildz v11.0.0 — Continuity, Messages and Receiz v128

Release date: 2026-10-04. Public-release baseline: v10.0.0 (`6f8dccc`). Includes the v10.1.0 source release (`b1238ad`) and every subsequent change.
Application version: `11.0.0`. Installed-PWA coordinate: `v11.0.0-r1`.

## Changes since the last release

- Add message notifications, reliable push setup and restored messenger layout.
- Restore the complete capture animation.
- Unblock unrelated Vault imports when existing cards are dead or retirement records cannot be resolved.
- Preserve upload and save continuity through interruptions and renew wallet sessions without upload races.
- Stabilize harvest movement and prevent double-tap zoom.
- Upgrade SDK, MCP server and AI skills together to exact public Receiz 128.0.0.

World-creature and unbounded-world design documents are included in the source ledger; those plans do not claim implemented gameplay.

The release also includes all v10.1.0 startup and gameplay performance improvements, distinct Glide/Flight controls, stronger identity and Vault saves, canonical offline recovery, wallet totals and transfer review fixes. See [v10.1.0 notes](v10.1.0.md) for those details.

## Compatibility and release identity

Receiz v128 retains ruleset 127.0.0 and registry digest `8d0b5b839d02d9efbd4306cc99410595a183705c2670b76d2567eaaaade99065`.
The exact 60-operation matrix digest is `940c316b5b7d6212240e699d03b3c1fd419cbbecc6ee51ddd7aa7783d9e523b0` and compatible SDK range is `>=128.0.0 <129.0.0`.
Contracts and generated evidence use the installed SDK matrix. Historical proof bytes and protocol identifiers remain unchanged. Host builds must set NEXT_PUBLIC_WILDZ_SW_RELEASE to v11.0.0-r1.
