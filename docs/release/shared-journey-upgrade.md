# Shared journey upgrade

## Delivered

The Living Story drawer connects actual companion ownership, spendable materials, discovery geometry and owned construction into a next-adventure loop. Players can pursue a home or choose exploration immediately. An unfinished shelter takes priority over gathering for another one. Home directions use the actual nearest owned shelter; rest requires being within six metres in the outer world and uses the existing camp recovery rule. Workbench and cache guidance connects existing crafting and storage functions.

A bounded owner-scoped journal records observed companion arrivals, confirmed harvests/builds, newly discovered sites and shelter rest. Meeting coordinates come from the actual encounter placement. Imported companions are not given fabricated meeting histories. The journal is explicitly local to this device, separate from portable creature proofs; it does not currently travel inside an Identity Seal. Existing companion work capabilities remain authoritative.

Discovery guidance selects actual unvisited sites, gives compass direction/distance and a family-specific exploration cue. Newly visited sites are remembered with the companion present. No invented items, rewards or new world geometry are generated by these cues.

Harvest rewards no longer wait for the former artificial 720 ms minimum. Work presentation still starts immediately and settles after confirmed admission. The Φ amount leads the feedback message. The drawer shows verified owner-bound world-work earnings with replay/duplicate/tamper filtering and a bounded verification cache shared across worker clones.

Existing exact rates are preserved: solo stone Φ0.01; solo timber/hay Φ0.02; a helping companion can increase these. A remaining Φ0.001 can be awarded subject to the existing global, region and contribution-class supply ceilings. This change improves pacing and visibility, not the emission multiplier or wallet balance. No replacement reward proofs or identity migrations were introduced.

Local playtest tooling records bounded frame gaps, long tasks and coarse action outcomes only when enabled. Manual great/stuck markers and JSON export support the accompanying local-playtest-guide.md. Sampling pauses in hidden tabs; no recordings are uploaded. Turning off recording clears the session.

## Remaining validation and scope

This patch is local and has not been deployed. Production bjklock card/profile publication needs a live regression after deployment; this turn did not use the original Identity Seal. Existing prior latency/publication changes are documented separately in interaction-latency-and-seal-publication.md.

Long-term player retention, delight, cross-device journal portability, richer companion AI recollection, homes attracting autonomous visitors, and a broader authored discovery catalog are not established by this patch. Actual human playtests and production/device performance comparisons remain necessary. Home recovery and construction admission have reducer/model coverage; the browser session did not construct a complete home from zero materials.
