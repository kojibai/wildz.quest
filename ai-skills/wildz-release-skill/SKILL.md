# Wildz v3 Release

Receiz proof authority and verified, sanitized evidence define release truth. Target Wildz `3.0.0` with `@receiz/sdk`, `@receiz/mcp-server`, and `@receiz/ai-skills` `^103.0.0`, resolved together at major 103.

## Procedure

1. Start with read-only diagnostics: inspect the exact diff, requested and installed versions, idle processes, and required environment names without printing values.
2. Run the deterministic local gate on the exact candidate: tests, typecheck, lint, secret scan, build, and default doctor.
3. Run strict-live only with an authorized environment. A configured value is not capability proof; record actual sanitized probe status and stop on failure.
4. Validate every external artifact writer from sanitized provenance and recomputed digests. Do not infer compatibility from a filename, fixture, or package installation.
5. Exercise WebKit and Chromium, required dimensions, direct safe API reads, accessibility, renderer recovery, offline/install/update behavior, configured and unavailable market modes, and current-Wildz export readers.
6. Record exact commands and results. Mark pending or failed evidence honestly; never convert missing evidence into a pass.

MCP and AI skills never outrank SDK proof verification. Deployment, tagging, pushing, publication, credential changes, private-artifact access, release creation, or any live mutation requires explicit human confirmation. Never print secrets or private evidence.
