# Wildz v4.0.0-alpha.1 — Kai and mobile reliability alpha

Wildz `v4.0.0-alpha.1` is the reliability follow-up to the competitive gameplay alpha. It restores the original Genesis-counted Kai Klok display contract, makes night lighting automatic, repairs stale-PWA upgrades, and protects the mobile controls from Android standalone browser chrome.

## What changed

- Current Kai is again counted from the established Genesis anchor. A persisted world-event cursor orders admitted state transitions but can never impersonate the current Kai Klok.
- Kai `uPulse` remains the temporal state-machine root for proof objects, world events, replay, settlement, history, and conflict resolution. ISO timestamps remain descriptive interoperability metadata.
- The flashlight/lantern appears automatically from authored darkness. The manual icon, keyboard shortcut, and toggle are removed.
- Service-worker navigation is network-first with a safe offline fallback. A newly installed worker activates immediately, and an already-open client reloads once when controller ownership changes, preventing stale HTML from requesting missing deployment chunks.
- Android standalone PWA controls receive an additional coarse-pointer bottom inset so the D-pad and companion control remain above system navigation chrome.

## Gameplay and proof continuity

The competitive Arena, exact-card progression, complete creature-history Vault transport, canonical settlement journal, retirement quarantine, and Receiz v118 authority boundaries from `v4.0.0-alpha.0` remain intact. No Kai Klok arithmetic was replaced in this release; the correction is at the runtime boundary that had confused an event cursor with current Kai.

The coordinated toolchain remains exactly `@receiz/sdk 118.0.0`, `@receiz/mcp-server 118.0.0`, and `@receiz/ai-skills 118.0.0`. First admission only, then append forever remains the durability law; deferred v119 orchestration is not shipped.

There is no external database added by Wildz. Offline reads remain limited to previously visited public profiles and previously visited public cards. Sign-in, the live world, social presence, market operations, and every mutation require a connection and admitted authority. A queued proposal is not a global commit.
