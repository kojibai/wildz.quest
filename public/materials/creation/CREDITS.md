The source maps are public-domain assets under CC0 1.0:
https://polyhaven.com/license
https://creativecommons.org/publicdomain/zero/1.0/legalcode

These bundled 256px and 512px WebP derivatives include diffuse colour, OpenGL normal, and roughness maps.
The manifest records source URLs, authors, hashes and output sizes.
scripts/build-creation-materials.mjs reproduces the derivatives using the project's existing open-source Sharp tool.

The hay fibre fallback is authored in this project. No remote material API is called during gameplay.
